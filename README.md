# Cloudflare Pages 纯官方极速直连版（零第三方依赖 · 完整脱敏）

本代码已完成 **100% 隐私脱敏**，密码、UUID、域名全部通过 Cloudflare 环境变量注入，不含任何个人隐私信息。移除所有第三方个人反代，纯走 Cloudflare 官方原生 Anycast 骨干网，支持 5 大地区多端口分流与一键健康度检测。

---

## 极简部署教程（3 步上线）

### 第 1 步：上传代码到 Cloudflare Pages
1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 左侧菜单点击 **Workers 和 Pages** -> **Pages** -> **创建项目** -> 选择 **直接上传 (Direct Upload)**。
3. 项目名称随意填（例如 `my-vpn-site`），把包含 `_worker.js` 的文件夹拖入上传，点击 **部署站点**。

---

### 第 2 步：设置环境变量（核心隐私参数）
进入该项目详情页 -> **设置 (Settings)** -> **环境变量 (Environment variables)** -> **生产环境 (Production)**，添加变量：

#### 必填变量（只有 1 个）：
| 变量名 | 推荐类型 | 是否必须 | 说明与示例 |
| :--- | :--- | :--- | :--- |
| `ADMIN` | **Secret (加密文本)** | **【必须设置】** | **管理后台密码兼订阅密钥**。例如：`MySuperPassword123` |

#### 可选变量（不填均有自动默认值）：
| 变量名 | 类型 | 是否必须 | 默认值（不填时） | 补充说明 |
| :--- | :--- | :--- | :--- | :--- |
| `UUID` | Plain text | 可选 | **自动生成**（根据 `ADMIN` 密码哈希自动计算生成唯一固定的 UUID） | 若想指定专属 UUID 可填（如 `ee9e38b3-b701-4c5a-8a6b-bacf4116cd14`）；不填也能自动算出来正常用 |
| `URL` | Plain text | 可选 | `nginx`（默认显示 Nginx 欢迎页） | 推荐填 `1101`，访问根目录时会伪装成 Cloudflare 官方 Error 1101 报错页，防探测性更强 |
| `OFF_LOG` | Plain text | 可选 | 未开启关闭（即默认会记录日志） | 推荐填 `1`，彻底关闭后台访问日志写入，避免占用 KV 容量并保护隐私 |

> **提示**：
> 1. **最简上线**：你甚至可以**只设置一个 `ADMIN`**，系统就会自动推导 UUID 并以默认配置平稳运行！
> 2. **完全不用填 `PROXYIP`**：本版本已实现纯官方 Anycast 直连，彻底剔除了任何第三方中转。

---

### 第 3 步：绑定自定义域名
1. 在项目详情页点击 **自定义域 (Custom domains)** -> **设置自定义域**。
2. 输入你解析在 Cloudflare 上的二级域名（例如 `sub.yourdomain.com`），点击继续并绑定。
3. 等待 1~2 分钟 SSL 证书生成完成。

---

### 第 4 步（可选）：绑定 KV 命名空间（用于后台保存配置）
如果你希望在 `/admin` 后台保存自定义优选 IP 列表、修改配置或持久化存储：
1. 在 Cloudflare 控制台左侧菜单点击 **Workers 和 Pages** -> **KV** -> 点击 **创建命名空间**（名称随意，如 `my_kv`）。
2. 进入你的 Pages 项目 -> **设置 (Settings)** -> **函数 (Functions)** -> 找到 **KV 命名空间绑定 (KV namespace bindings)**。
3. 点击 **添加绑定 (Add binding)**：
   - **变量名称 (Variable name)**：**必须填写大写 `KV`**（因为后端代码固定使用 `env.KV` 读写数据）。
   - **KV 命名空间 (KV namespace)**：下拉选择刚才第 1 步创建的命名空间。
   - 点击 **保存** 即可。

> **提示**：如果不绑定 KV 也不影响翻墙，系统会自动使用内置默认配置正常工作。

---

## 使用与管理
- **管理后台**：访问 `https://你的域名/admin`，输入你设置的 `ADMIN` 密码即可登录。
- **一键检测**：登录后台后，点击 **【⚡ 一键检测】** 可秒级探测当前运营商识别、官方直连延迟和真实出站机房。
- **节点订阅**：支持直接复制 **Clash (YAML)**、**Base64** 与 **通用 VLESS** 链接，或直接用手机客户端扫码导入。
